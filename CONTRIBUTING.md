# Contributing to Awesome AI Music

Thanks for your interest in contributing! This list is community-driven and we welcome additions, corrections, and improvements.

## How to Add an Entry

1. **Fork** this repository.
2. **Add your entry** in the appropriate section of `README.md`.
3. **Follow the formatting**: `- [Name](url) — Brief one-line description.`
4. **Keep entries alphabetical** within each section (except where explicitly ordered by relevance or popularity).
5. **Open a pull request** with a clear title and description explaining what you added and why.

## Formatting Rules

### Entry Format

```markdown
- [Project Name](https://example.com) — One-sentence description of what it does.
```

- Use an em-dash (`—`), not a hyphen (`-`), between the link and description.
- End descriptions with a period.
- Keep descriptions under ~120 characters.

### Section Structure

If you're proposing a new category or section, open an issue first to discuss before submitting a PR.

## Guidelines

### What We Accept

- **Open-source projects** with an active maintainer (commits in the last 12 months).
- **Commercial tools** that are genuinely useful to AI music developers or creators.
- **Research papers, datasets, and tutorials** with direct relevance to AI music generation.
- **Communities** where developers actively discuss AI music work.

### What We Reject

- Listicles or blog posts masquerading as tools.
- Abandoned projects (no meaningful activity in 2+ years).
- Tools that only tangentially relate to AI music (e.g., generic ML libraries unless they have a specific audio focus).
- Self-promotional repos with no actual functionality.
- Affiliate links or paid placements.
- Duplicate entries (check the list first).

## Pull Request Checklist

Before submitting:

- [ ] My entry is in the correct section.
- [ ] My entry follows the formatting rules above.
- [ ] The link works and points to the canonical project/tool page.
- [ ] The description is concise and accurate (not marketing copy).
- [ ] I have not duplicated an existing entry.
- [ ] If I'm proposing a new section, I opened an issue to discuss first.

## Reporting Broken Links or Outdated Info

Found a broken link or a tool that's been abandoned? Open an issue or PR — we'll merge promptly.

## Questions?

Open an issue or reach out to the maintainers via the repository discussions.

Thanks for helping keep this list useful for the community!
